Set up Widen

About a minute, in three places: the Widen app, the Settings app, then Safari.

  1. In the Widen app

    Open Widen

    Tap Safari Settings. It takes you straight to Widen’s page in the Settings app. iOS only lets you, not apps, switch on a Safari extension, so this is the one step you do yourself.

  2. In Settings

    Allow Widen

    Switch Allow Extension on. Then, under Permissions, set All Websites to Allow (it’s called Other Websites if you’ve already allowed a site by name), so Widen can work on every page you open. If you use Private Browsing, switch that on too.

    You’ll find the same page later in Settings › Apps › Safari › Extensions › Widen.

  3. In Safari

    Close your iPhone Duo and browse

    That’s it: every site opens in Pictures mode, and your free week starts with the first page Widen widens.

    To change the mode, or give one site its own setting, tap the menu button at the left of Safari’s address bar, then choose Widen.

  4. Optional, in Control Center

    Add the Widen button

    Open Control Center, tap + at the top, then Add a Control, and choose Widen. Each tap of the button steps through Off, Pictures and Pictures & text for every site, and it shows which is on. Safari uses the new choice from the next page you open.

Stuck? The FAQ covers each Safari setting, and the support page has the rest.
